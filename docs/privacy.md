# Privacy and data handling

9-gyo-φ is designed to work without an account, telemetry service, or document-processing cloud.

## Data that stays local

- imported documents and their extracted passages;
- notes, favorites, bookmarks, reading position, and Text studio drafts;
- generated M4B audiobooks and saved audiobook position;
- optional Qwen and Kokoro model files;
- application logs generated by the local Tauri runtime.

Library data is stored in the WebView's IndexedDB database. M4B files and model weights are stored in the application's operating-system data directory. The application does not encrypt this data; device account security and disk encryption remain important.

## Network access

Network access occurs only when the user:

- imports a public HTTP or HTTPS URL;
- installs the optional Qwen model;
- uses Kokoro before its native model and voice packs are installed;
- runs development or dependency tooling.

Document text is not sent to the model hosts. Downloads contain ordinary HTTP metadata such as IP address and user agent, as with any file download.

## Speech behavior

- Native Qwen preparation runs through a loopback-only llama.cpp process.
- Native Kokoro runs through Rust and ONNX Runtime.
- Browser cloud voices are intentionally excluded.
- Deterministic local rules remain available when the LLM is missing or disabled.

## Deletion and backups

Recently deleted documents are recoverable inside the app. Removing application data through macOS or browser settings can permanently remove the library, models, and audiobooks. Export a library backup and original documents before clearing application data.

Backups are unencrypted JSON and may contain complete documents and notes. Store them with the same care as the source material.

## No analytics

The project contains no advertising SDK, analytics SDK, crash-reporting service, account system, or cloud synchronization. If that changes, it must be documented before release and require an explicit product decision.
