# Support

Use the channel that best matches your question:

- **Questions, setup help, and early ideas:** [GitHub Discussions](https://github.com/anpu-ai-official/9-gyo-phi/discussions)
- **Reproducible bugs:** [GitHub Issues](https://github.com/anpu-ai-official/9-gyo-phi/issues/new/choose)
- **Security or privacy vulnerabilities:** [Private vulnerability report](https://github.com/anpu-ai-official/9-gyo-phi/security/advisories/new)

Before reporting a problem, run `npm run verify`, check the existing issues, and include the app version, macOS version, Mac chip, document format, and selected voice engine.

Do not upload copyrighted books, private documents, application storage, model files, API credentials, or personal data. A small synthetic reproduction is much easier and safer to investigate.
